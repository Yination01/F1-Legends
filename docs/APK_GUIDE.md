# APK Build Guide - F1 Clash Zero v5.2

## Why cloud build?
Sandbox building needs >1GB RAM and Gradle daemon gets OOM-killed. Use GitHub Actions (free) or local build.

## Option 1: GitHub Actions (recommended, zero-dollar)
1. Push to `main` branch on https://github.com/Yination01/F1-Legends
2. Actions tab -> Build APK -> Run
3. Download artifact `F1-Clash-Zero-debug` (app-debug.apk)
4. Install on Android: `adb install app-debug.apk` or transfer to phone.

Workflow file: `.github/workflows/build-apk.yml`
- Sets up Node 18, Java 17, Android SDK 34
- `npm install` in app/
- `node copy-game.js` copies ../game -> www
- `npx cap add android`
- `./android/gradlew assembleDebug`
- Uploads APK as artifact + creates Release tag v5.2-*

## Option 2: Local build
Requirements: JDK 17, Android SDK 34

```bash
# Install SDK (once)
mkdir -p ~/Android/Sdk/cmdline-tools
cd ~/Android/Sdk/cmdline-tools
wget https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip *.zip && mv cmdline-tools latest
export ANDROID_HOME=~/Android/Sdk
export PATH=$ANDROID_HOME/cmdline-tools/latest/bin:$PATH
yes | sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

# Build
cd F1-Legends/app
./build-apk.sh
```

APK output: `F1-Clash-Zero-debug.apk` (root)

## Option 3: PWA Install (no APK)
Game is pure HTML/JS, works as PWA:
- Open `game/index.html` in Chrome Android -> Add to Home Screen
- Or host on GitHub Pages / Netlify, then use https://www.pwabuilder.com/ to generate APK from URL.

## Capacitor Config
- appId: `com.f1clashzero.game`
- appName: `F1 Clash Zero`
- webDir: `www` (generated by copy-game.js)
- Plugins: @capacitor/preferences (save slots)

## Troubleshooting
- `Android Gradle plugin requires Java 17` -> set JAVA_HOME to JDK 17
- `SDK not found` -> set ANDROID_HOME
- Gradle OOM -> add to android/gradle.properties: `org.gradle.jvmargs=-Xmx512m`
- Preview server: `cd game && python3 serve.py` -> http://localhost:8000
